# Практические работы

Репозиторий содержит материалы практичесих работ в рамках курса «Бэкенд-разработка на языке Go».

## № 1. Знакомство с Go

### Версии инструментов
**Go:** 1.27.2 

### Выполненные задания и команды запуска

#### 1. Первая программа
**Запуск:** `go run .`
**Сборка и запуск:** 
Windows: `go build -o hello.exe .` и `.\hello.exe`
macOS/Linux: `go build -o hello .` и `./hello`

#### 2. Карточка участника
**Запуск:** `go run ./cmd/card`

#### 3. Конвертер минут
**Запуск:** `go run ./cmd/time-converter` 

## № 2. Условия, циклы, функции и коллекции

Добавлен файл, в котором реализованы функции:
1) перевода статусов на русский через switch-case
2) подсчёта количества заданного статуса в массиве через перебор циклом for и сравнением
3) cтатистики (подсчета количества заданного статуса) через map
4) доп. задание:
	1)  нахождение индекса первого заданного статуса в массиве
	2) подсчёт процента выполненных задач

**Запуск:** `go run ./cmd/task-summary`
