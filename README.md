# Практическая работа № 1. Знакомство с Go

Репозиторий содержит материалы практической работы № 1 в рамках курса «Бэкенд-разработка на языке Go».

## Версии инструментов
**Go:** 1.27.2 
## Выполненные задания и команды запуска

### 1. Первая программа
**Запуск:** `go run .`
**Сборка и запуск:** 
Windows: `go build -o hello.exe .` и `.\hello.exe`
macOS/Linux: `go build -o hello .` и `./hello`

### 2. Карточка участника
**Запуск:** `go run ./cmd/card`

### 3. Конвертер минут
**Запуск:** `go run ./cmd/time-converter`
